# ALTIERA — Luxury Local Fragrance Landing Page

Website landing page statis untuk ALTIERA, dibuat mobile-first dan siap di-deploy ke Netlify.

## Cara preview
1. Ekstrak ZIP.
2. Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code.
3. Koneksi internet dibutuhkan untuk memuat Tailwind CSS CDN.

## Deploy ke Netlify
1. Masuk ke Netlify.
2. Pilih **Add new site** → **Deploy manually**.
3. Drag & drop folder `altiera-landing-page` yang sudah diekstrak (atau upload ZIP ini sesuai opsi yang tersedia).
4. Netlify akan menerbitkan URL demo.

## Isi paket
- `index.html` — HTML, Tailwind CSS, CSS tambahan, dan JavaScript dalam satu file.
- `assets/` — foto produk, logo, dan video yang diberikan.

## Catatan
- Semua tautan CTA menggunakan tautan resmi yang diberikan di brief.
- Klaim ketahanan, keamanan kain, gratis ongkir, dan garansi ditampilkan sebagai informasi brand dengan catatan bahwa hasil/persyaratan dapat berbeda. Pastikan syarat promo dan garansi sesuai kebijakan toko sebelum dipublikasikan.
- Tailwind CSS dimuat melalui CDN sehingga perlu koneksi internet saat membuka halaman.
